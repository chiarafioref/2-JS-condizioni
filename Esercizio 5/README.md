# ESERCIZIO

Chiedi l'età all'utente. Se è minorenne stampa "Ciao", se è over60 stampa "Salve", altrimenti stampa "Benvenuto"

## RAGIONAMENTO

- Chiedi all'utente di inserire la sua età
  - SE l'età è minore di 18 
    - stampa "Ciao"
  - ALTRIMENTI SE l'età è maggiore di 60
    - stampa "Salve"
  - ALTRIMENTI
    - stampa "Benvenuto"
