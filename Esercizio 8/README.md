# ESERCIZIO

Chiedi username e password. Se sono rispettivamente "admin" e "1234", stampa "Login effettuato", altrimenti stampa "Credenziali errate".

## RAGIONAMENTO

- Chiedi all'utente di inserire il suo username
- Chiedi all'utente di inserire la sua password
   - SE l'username è "admin" e la password è "1234"
     - stampa "Login effettuato"
  - ALTRIMENTI 
     - stampa "Credenziali errate"
