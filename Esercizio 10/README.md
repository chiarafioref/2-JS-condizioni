# ESERCIZIO

Chiedi quante ore si resta nel parcheggio. Se sono <= 2 ore costa 5€, se sono <= 5 ore costa 10€, altrimenti costa 15€.

## RAGIONAMENTO

- Chiedi all'utente per quante ore sosterà nel parcheggio
  - SE le ore sono minori o uguali a 2
    - stampa il prezzo di 5€
  - ALTRIMENTI SE le ore sono minori o uguali a 5
    - stampa il prezzo di 10€
  - ALTRIMENTI 
    - stampa il prezzo di 15€
